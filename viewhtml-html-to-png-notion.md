# Export an HTML prototype as PNG for Slack and Notion

Not everyone opens local HTML. Preview the prototype cleanly, then export PNG at a realistic width (390 mobile / 1280 desktop).

[ViewHTML](https://viewhtml.app/) combines live preview with PNG and PDF export so you avoid "screenshot of my editor at the wrong zoom". Name files `screen-state-viewport.png`, paste into Slack with one sentence of context, and keep the HTML as the editable source beside the image.
