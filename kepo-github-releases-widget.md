# Turn GitHub release notes into Mac desktop widgets

Every public repo publishes `https://github.com/OWNER/REPO/releases.atom`. Those Atom feeds are perfect for a quiet "versions" panel on your desktop.

Pick five to twelve dependencies you actually run. Skip toys you starred once. Surface the feeds with [Kepo](https://kepo.ai/) as a macOS widget named Versions, placed near your terminal. Each morning: skim titles, open only security or major bumps, file a short bump todo.

Desktop beats notification centre here — GitHub pings compete with CI noise; a dedicated widget creates a deliberate review habit.
