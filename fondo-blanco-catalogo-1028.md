# Quitar fondo para un catálogo con fondo blanco

Antes de publicar, [quitar fondo](https://fondoblanco.org) y dejar [fondo blanco gratis](https://fondoblanco.org) ayuda a que el pack se vea uniforme.

También uso [poner fondo blanco](https://fondoblanco.org) en fotos de producto y guardo una [foto con fondo blanco](https://fondoblanco.org) lista para el listing.
