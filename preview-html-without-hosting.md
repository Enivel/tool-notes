# Previewing and sharing an HTML file without hosting

You have a single HTML file: an email template, a landing page draft, a report generated by a script, or a page an AI assistant just wrote. You want to see it rendered and maybe send it to someone. Setting up hosting for that is overkill.

## The quick way

Paste or upload the file into [ViewHTML](https://viewhtml.app/), a free online HTML viewer. It renders the page instantly in the browser, lets you edit the code with a live preview, and gives you a link you can share.

## A short checklist before you share

- **Inline your CSS** or use absolute URLs for stylesheets, otherwise the preview will look unstyled.
- **Check images**: relative paths like `img/logo.png` will not resolve; use full URLs or data URIs.
- **Resize the preview** to a phone width to catch layout problems early.
- **Remove secrets**: API keys or internal URLs sometimes end up in generated HTML.
- **Validate links**: click through every link once in the preview.

## When to use real hosting instead

If the page needs a backend, forms that submit data, or a custom domain, use a proper static host. For everything else — reviews, demos, quick feedback — a viewer link is faster.
