# Debug broken CSS with an instant HTML preview

CSS bugs love host environments. Build a minimal HTML reproduction, include only the suspect CSS, and preview it in isolation before blaming the framework.

[ViewHTML](https://viewhtml.app/) lets you paste HTML for a clean live preview and share a link when you need a second pair of eyes. Change one rule at a time. Export a PNG of the broken state for the ticket. Instant preview will not replace DevTools — it gets you there with a smaller patient.
